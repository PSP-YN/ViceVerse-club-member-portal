# ViceVerse Club Member Portal 🌴🌆

Welcome to the **ViceVerse Club Member Portal**, a premium and exclusive platform for managing club members, events, and operations. Inspired by the vibrant and iconic aesthetic of **GTA 6 Vice City**, the portal features a rich neon color palette with sleek dark mode aesthetics.

## ✨ Features

- **GTA 6 Vice City Theme**: A custom UI featuring neon pinks, cyans, and deep purple-blue backgrounds for a true premium feel.
- **Member Dashboard**: Seamlessly manage and view your membership status and details.
- **QR Code Scanning**: Built-in support for HTML5 QR codes for events or quick access passes.
- **Modern Tech Stack**: Built with [Next.js 16](https://nextjs.org), React 19, and TailwindCSS v4.
- **Responsive Design**: Flawless experience on both desktop and mobile platforms.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository and navigate into the `CLUB_MEMBER` directory.
2. Install the dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the vibrant portal in action.

## 🛠️ Built With

- **Next.js**: The React Framework for the Web.
- **TailwindCSS**: A utility-first CSS framework (customized with OKLCH theme).
- **Supabase**: Backend-as-a-Service for database and authentication.
- **Shadcn UI & Base UI**: High-quality, accessible UI components.

## 🚀 Deployment

The portal is optimized for deployment on [Vercel](https://vercel.com). Just link your repository to Vercel and it will automatically deploy the `master` branch.

```bash
npx vercel --prod
```
